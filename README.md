# Agentic-Ready Repository Template

A GitHub repository template for building projects with agentic and loop engineering practices from day one.

## Purpose

Provide a reusable foundation for human and AI collaboration, with intentional repository defaults, automated feedback loops, and reusable agent capabilities.

## Planned capabilities

- **Repository defaults:** repeatable configuration for repository settings and collaboration policies.
- **Workflows:** automation for planning, implementation, verification, review, and maintenance.
- **Skills:** reusable task-specific instructions and tools.
- **Agents:** role-specific instructions for scoped, coordinated work.
- **Engineering loops:** clear acceptance criteria, bounded execution, actionable feedback, and human oversight.

This repository currently contains only the initial project outline. These capabilities will be introduced incrementally.

## Use this template

Select **Use this template → Create a new repository** on GitHub to start a project from this repository's files.

GitHub template repositories copy files, not all repository settings, secrets, or permissions. Any required configuration will be documented as it is introduced.

## Design principles

- Keep the foundation language- and framework-neutral.
- Prefer small, composable conventions over a heavy framework.
- Make agent instructions explicit, discoverable, and version-controlled.
- Build short, verifiable feedback loops with explicit stopping conditions.
- Use least-privilege automation and human approval for consequential actions.
- Distinguish reusable template content from project-specific configuration.
